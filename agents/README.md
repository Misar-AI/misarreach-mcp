# MisarReach agents

Task-scoped agents built on the @misarreach/mcp MCP server. Each bundles a subset
of the tools with the rules for using them safely.

| Agent | Purpose |
| --- | --- |
| `lead-researcher` | Discovers and enriches companies and leads, verifies emails, and scores the list before any outreach. |
| `outreach-operator` | Builds and previews multi-channel sequences, then sends to campaign only after explicit approval. |
| `pipeline-manager` | Reviews deals, moves stages on real signals, and reports pipeline health. |

All of them require authentication — see https://docs.misar.io/reach/mcp. Generated by
`scripts/mcp/generate-distribution.mjs`; edit the product entry, not these files.
